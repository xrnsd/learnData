**not only … but (also) … (as well)** 不仅……而且……
**as well** = also（放在句尾，用来再次强调“也”）
**of + 抽象名词** 的用法
| 结构                | 等价表达                   |
| of immense size     | immensely large / very big |
| of great importance | very important             |
| of no value         | worthless                  |
> It is not only of immense size, but **(it)** is extremely accurate as well.
后面的 **it** 省略了，这是并列结构中非常常见的省略。

* It is not only of ++immense+ size, ++but+ is **extremely accurate as well*. \U0001F4CC
