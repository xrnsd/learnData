*  **has now increased 的意思**
**has increased**：现在完成时，表示“已经增加了”，强调从过去到现在的**变化结果**。
**now**：强调“现在已经……了”，起到时间点的提示作用。

* Because the tree was ++mentioned+ in a newspaper, the number of visitors to Frinley **has now* ++increased+. \U0001F4CC
* Because the tree was **mentione*++d in+ a newspaper, the number of visitors to Frinley has now **increased*. \U0001F444
